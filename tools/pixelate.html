Sprite Conditioner

Image generators produce pixel-flavoured pictures: soft edges, thousands of near-identical colours, an inconsistent grid. This snaps one to a real pixel grid, cuts the palette down, and knocks out the background — so a generated portrait actually sits in the room instead of floating above it. Everything happens in this page; nothing is uploaded anywhere.

Pixel grid

168 matches a character standing at the counter in the 384×216 room. Smaller is chunkier.

Colour

Snapping keeps the sprite in the same candlelight range as the room. Turn it off if it is flattening the skin tones.

Background

Fills inward from the edges, so parts of the figure that happen to match the backdrop are safe. Raise it if flecks of background survive; lower it if it starts eating the character's outline.
